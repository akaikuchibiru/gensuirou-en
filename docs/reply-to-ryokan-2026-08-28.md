## 何が起きていたか

新サイトへの切り替えの際、**「ご予約」ボタンの行き先を、
予約サイト（プラン・料金・空室が見られるページ）ではなく、
お問い合わせフォームに変えてしまっておりました。**

そのため、お客さまが「ご予約」を押しても、
料金の確認も空室の確認もできず、フォームが出るだけの状態になっておりました。
「金額の確認と予約ができない」「問い合わせが見にくい」というのは、
まさにこのことだと思います。

予約サイト自体は問題なく動いております。**行き先だけが間違っておりました。**

## 直した内容

**1. 「ご予約」から、これまでどおり予約サイトへ行くように戻しました**

サイトのどのページからでも、「ご予約」を押すと
プラン・料金・空室状況をご覧いただけるページへ進みます。
（以前と同じ予約サイトです）

**2. お電話を、予約サイトと同じ大きさで並べました**

お電話のほうが確実、とのことでしたので、
「WEBで予約する」と「お電話で予約する」を**横に並べて同じ大きさ**にしております。

    ┌─────────────────┐  ┌─────────────────┐
    │ WEBで予約する      │  │ お電話で予約する    │
    │ プラン・料金・空室   │  │ ご相談・直前のご予約 │
    │ [プラン・料金を見る] │  │ [096-279-1800]  │
    └─────────────────┘  └─────────────────┘

**3. お問い合わせフォームは、その下に移しました**

ご予約が先、お問い合わせはその下、という並びにしております。
フォームをなくしてはおりませんので、
メールでのご相談をご希望のお客さまはこれまでどおりお使いいただけます。
